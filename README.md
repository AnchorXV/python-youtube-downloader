\# yt-downloader



Educational project: YouTube downloader with Python.



⚠️ For educational purposes only. Use only with your own content or freely licensed content.



\## Setup

1\. Create a virtual environment: `python -m venv .venv`

2\. Activate: `.venv\\Scripts\\activate` (Windows) / `source .venv/bin/activate` (Mac/Linux)

3\. Install: `pip install -r requirements.txt`

4\. Run: `python src/ytdl/cli.py --help`
